# Personal GitHub Identity

This repository is pushed using the personal GitHub account `Sumitsahani`.
Commit author email: `sumitsahani.1855@gmail.com`.

Set identity locally in this repository:

```sh
git config --local user.name Sumitsahani
git config --local user.email sumitsahani.1855@gmail.com
git config --local credential.https://github.com.username Sumitsahani
```

Authenticate as `Sumitsahani` before pushing. Commit email alone does not select
the authenticated GitHub account. Do not push using a company account.
